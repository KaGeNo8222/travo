# Checklist ทดสอบบน iPhone

ส่วนที่ทดสอบอัตโนมัติจาก Windows ไม่ได้ ให้ทำบน iPhone จริงกับเวอร์ชันที่ deploy บน **HTTPS** แล้ว (ดูหัวข้อ Deploy ใน README) จดรุ่นเครื่องและเวอร์ชัน iOS ไว้ทุกครั้งที่ทดสอบ

**อุปกรณ์:** ______________ **iOS:** ______________ **วันที่:** ______________ **เวอร์ชันแอป** (ตั้งค่า → เกี่ยวกับ): ______________

## 1. ติดตั้งและเปิดครั้งแรก

- [ ] เปิด URL ใน Safari แล้วหน้า "ทริปของฉัน" แสดงเป็นภาษาไทย ไม่มี scroll แนวนอน
- [ ] แชร์ → เพิ่มไปยังหน้าจอโฮม: ไอคอน TRAVO (หมุดสีขาวบนพื้นกรมท่า) ชื่อ "TRAVO"
- [ ] เปิดจากหน้าจอโฮมแล้วไม่มีแถบ Safari (standalone) และ header/bottom nav ไม่ชน notch หรือ home indicator
- [ ] ขึ้น toast "พร้อมใช้งานแบบออฟไลน์แล้ว" (ครั้งแรก)
- [ ] ตั้งค่า → พื้นที่จัดเก็บ: แสดงขนาดที่ใช้ และสถานะการจัดเก็บถาวร

## 2. ทริปและ dashboard

- [ ] สร้างทริปใหม่: พิมพ์ประเทศ "ญี่ปุ่น" แล้ว timezone เปลี่ยนเป็น Asia/Tokyo และสกุลเงินเป็น JPY อัตโนมัติ
- [ ] แตะช่องข้อความ/วันที่แล้วหน้าจอ **ไม่ซูม** คีย์บอร์ดไม่บังปุ่ม "บันทึก" ด้านล่าง
- [ ] เลือกรูปปกจากคลังรูป: แสดง preview และขนาดก่อน/หลังย่อ
- [ ] Dashboard แสดงเวลาท้องถิ่นของทริป (GMT+9) ไม่ใช่เวลาเครื่อง
- [ ] แก้วันที่ทริปให้สั้นลงขณะที่วันสุดท้ายมีกิจกรรม: มี dialog ให้เลือกวิธีจัดการ และกด "ยกเลิก" แล้วไม่มีอะไรเปลี่ยน
- [ ] ทำสำเนาทริปไปวันอื่น / เก็บถาวร / กดเลิกทำใน toast / ลบ (มีหน้ายืนยันแสดงจำนวนข้อมูล)

## 3. แผนรายวันและสถานที่

- [ ] เพิ่มสถานที่ด้วยลิงก์ `maps.app.goo.gl/...` ที่คัดลอกมาจากแอป Google Maps (ปุ่มวางทำงาน และขึ้นข้อความว่าเป็นลิงก์แบบย่อ)
- [ ] วางลิงก์ที่มี `@lat,lng` แล้วกด "ใช้พิกัดนี้": พิกัดถูกเติมให้
- [ ] กด "เปิดแผนที่" / "นำทาง": เปิดแอป Google Maps (ถ้าติดตั้งไว้) หรือหน้าเว็บ และกลับมาที่แอปได้
- [ ] เพิ่มสถานที่ชื่อซ้ำ: ขึ้นคำเตือนสถานที่ซ้ำ
- [ ] "เพิ่มลงแผน" จากหน้าสถานที่ → toast "ดูแผน" พาไปวันที่ถูกต้อง
- [ ] สร้างกิจกรรม 2 รายการที่เวลาซ้อนกัน: มีคำเตือนในฟอร์มและป้าย "เวลาซ้อน" ในการ์ด
- [ ] กิจกรรม 22:00–01:00 แสดง "+1"
- [ ] ปัดแถบเลือกวันได้ลื่น วันนี้มีจุดสีเขียว และวันที่เลือกเลื่อนมาอยู่กลางจอ
- [ ] จัดลำดับรายการที่ยังไม่กำหนดเวลาด้วยปุ่มขึ้น/ลง / ย้ายไปวันอื่น / ทำสำเนา / ข้าม / ทำเครื่องหมายว่าเสร็จ

## 4. ช้อปปิ้งและรูปภาพ

- [ ] ปุ่ม "ถ่ายรูป" เปิดกล้องหลังโดยตรง และรูปที่ได้ไม่กลับหัวหรือหมุนผิด
- [ ] ปุ่ม "คลังรูป" เลือกรูป HEIC/Live Photo ได้ และรูปถูกย่อ (ดูข้อความขนาดก่อน → หลัง)
- [ ] คัดลอกรูปจากแอปรูปภาพ แล้วกด "วาง": iOS แสดงปุ่ม "วาง" และรูปถูกเพิ่ม (ถ้าไม่ทำงาน ให้จดเวอร์ชัน iOS ไว้ เพราะปุ่มคลังรูปยังใช้แทนได้)
- [ ] แตะรูปสินค้าแล้วเปิดเต็มจอพร้อมชื่อตัวใหญ่ ปิดได้
- [ ] แตะวงกลมบนการ์ดสินค้า 1 ชิ้น → ซื้อแล้ว + toast เลิกทำ; สินค้าหลายชิ้นเปิดหน้าบันทึกจำนวนแทน
- [ ] ซื้อ 1 ใน 3 ชิ้นแล้วแสดง "ซื้อแล้ว 1/3" และยอด "จ่ายไปแล้ว" ถูกต้อง
- [ ] สลับมุมมองรูป/รายการ แล้วปิดและเปิดแอปใหม่: ยังจำมุมมองที่เลือกไว้
- [ ] ปิดแอปจาก app switcher แล้วเปิดใหม่: สถานะการซื้อและรูปยังอยู่ครบ

## 5. การจองและค่าใช้จ่าย

- [ ] เพิ่มเที่ยวบิน BKK 22:30 (Asia/Bangkok) → HND 06:40 วันถัดไป (Asia/Tokyo): แสดงระยะเวลา 6 ชม. 10 นาที และ "+1"
- [ ] ช่อง datetime-local ใช้ตัวเลือกวันเวลาของ iOS ได้ปกติ
- [ ] แนบ PDF ตั๋วจากแอปไฟล์ → เปิดดูในแอป → "แชร์ / เปิดในแอปอื่น" ทำงาน
- [ ] รหัสการจองแสดงเป็น •••• จนกว่าจะแตะรูปตา และปุ่มคัดลอกทำงาน
- [ ] ตั้งอัตรา 1 JPY = 0.235 THB แล้วสลับ "แสดงเป็น THB/JPY": ยอดเปลี่ยนตาม และงบประมาณคงเหลือถูกต้อง
- [ ] ยอดช้อปปิ้งที่ซื้อแล้วปรากฏในหน้าค่าใช้จ่ายพร้อมป้าย "จากรายการช้อปปิ้ง" โดยไม่ต้องบันทึกซ้ำ

## 6. ออฟไลน์

- [ ] เปิดโหมดเครื่องบิน แล้วปิดและเปิดแอปจากหน้าจอโฮมใหม่: แอปเปิดได้ และแสดงแถบ "ออฟไลน์"
- [ ] ขณะออฟไลน์: สร้าง/แก้ไขทริป กิจกรรม สินค้า (พร้อมรูปจากกล้อง) และการจองได้ และรูปเดิมแสดงครบ
- [ ] ขณะออฟไลน์ เปิดหน้าตั้งค่า (โหลดแบบ lazy) ได้
- [ ] กลับมาออนไลน์แล้วแถบออฟไลน์หายไป

## 7. สำรองและกู้คืน

- [ ] สร้างไฟล์สำรอง → "บันทึกไปที่แอปไฟล์ / แชร์" → บันทึกลง iCloud Drive สำเร็จ
- [ ] ตั้งค่าแสดงวันเวลาและขนาดของการสำรองล่าสุด
- [ ] กู้คืนแบบ "รวมกับข้อมูลเดิม → ข้าม": ไม่มีทริปซ้ำ
- [ ] กู้คืนแบบ "นำเข้าเป็นสำเนา": ได้ทริปใหม่ที่มี "(นำเข้า)" และรูปครบ
- [ ] ลบแอปจากหน้าจอโฮม (ข้อมูลหาย) → ติดตั้งใหม่ → "แทนที่ทั้งหมด" ด้วยไฟล์สำรอง: ทุกทริป รูป และการตั้งค่ากลับมาครบ
- [ ] เลือกไฟล์ที่ไม่ใช่ไฟล์สำรอง (เช่น PDF หรือ ZIP อื่น): มีข้อความ error และข้อมูลเดิมไม่เปลี่ยน
- [ ] ทดสอบไฟล์สำรองขนาดใหญ่ (ประมาณ 100–200 รูป): จดเวลาที่ใช้ และสังเกตว่าแอปไม่ค้างหรือปิดตัวเอง

## 8. การแสดงผลทั่วไป

- [ ] ตั้งค่าธีม "มืด" / "สว่าง" / "ตามระบบ" แล้วสลับ Dark Mode ของ iOS: สีตามที่ตั้งไว้ และไม่กะพริบตอนเปิดแอป
- [ ] เปลี่ยนภาษาเป็น English แล้วทุกหน้าแสดงภาษาอังกฤษ (รวม error และ validation)
- [ ] iPhone จอเล็ก (SE / mini) และจอใหญ่ (Pro Max): ไม่มี scroll แนวนอน ปุ่มกดง่ายด้วยนิ้วโป้ง
- [ ] หมุนจอแนวนอน: ยังใช้งานได้ แม้จะออกแบบให้แนวตั้งเป็นหลัก
- [ ] Deploy เวอร์ชันใหม่: แอปที่เปิดอยู่ขึ้นแถบ "มี TRAVO เวอร์ชันใหม่" และกด "อัปเดต" แล้วโหลดเวอร์ชันใหม่
